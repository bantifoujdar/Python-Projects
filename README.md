# 🎮 Tic-Tac-Toe Game (Python)

A simple command-line Tic-Tac-Toe game built using Python. This project allows two players to play against each other in the terminal. It includes input validation, winner detection, and draw detection.

## 📌 Features

- Two-player gameplay
- Command-line interface
- Input validation (accepts only numbers from 0–8)
- Prevents players from choosing an occupied position
- Automatically detects the winner
- Detects draw when the board is full
- Displays the game board after every move

## 🛠️ Technologies Used

- Python 3

## ▶️ How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the project files.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python "Tic-Tac-Toe game for College Project.py"
```

## 🎯 How to Play

- Enter the names of both players.
- Player 1 uses **X**.
- Player 2 uses **O**.
- Choose a position from **0 to 8** according to the board layout.

```
0 | 1 | 2
--|---|--
3 | 4 | 5
--|---|--
6 | 7 | 8
```

- The first player to align three symbols horizontally, vertically, or diagonally wins.
- If all positions are filled and no player wins, the game ends in a draw.
